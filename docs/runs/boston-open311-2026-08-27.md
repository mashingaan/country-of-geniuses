# Boston Open311 read-only run

Date: 2026-08-27

## Objective

Run `civic-problem-triage` against one current public Boston Open311 record without sending or preparing a duplicate request.

## Commands

The following requests are read-only and require no credential in this run:

```powershell
$serviceCode = 'Transportation - Traffic Division:Signs & Signals:Sign Repair'
$encoded = [uri]::EscapeDataString($serviceCode)
$listUri = "https://311.boston.gov/open311/v2/requests.json?service_code=$encoded&start_date=2026-07-01T00:00:00Z&end_date=2026-08-27T23:59:59Z&per_page=3&page=1"
Invoke-WebRequest -UseBasicParsing -Uri $listUri -Method Get

$requestUri = 'https://311.boston.gov/open311/v2/requests/101006740558.json'
Invoke-WebRequest -UseBasicParsing -Uri $requestUri -Method Get
```
